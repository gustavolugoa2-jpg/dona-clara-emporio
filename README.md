# Panificadora & Empório Dona Clara — Solução Digital

Este projeto foi desenvolvido por mim para a disciplina de Design Profissional, ministrada pelo Prof. Sedenilso Antonio Machado, com o objetivo de propor uma solução digital prática para o estudo de caso da Panificadora & Empório Dona Clara.

## Compreensão do Problema

A Dona Clara é uma panificadora artesanal com 12 anos de tradição na comunidade, gerida pelo casal Clara e Roberto. Apesar do sucesso histórico com vendas no balcão e no atendimento presencial, a rotina dos moradores do bairro mudou bastante com o aumento do trabalho remoto. Além disso, a chegada de concorrentes gourmet na região trouxe a necessidade urgente de modernização.

A dependência exclusiva de cadernos de papel para apontar encomendas vinha gerando falhas nos pedidos, atrasos na entrega de bolos e tábuas de frios, além de perda de clientes que preferem a praticidade de garantir o seu pedido sem enfrentar filas.

## Decisão de Design e Solução Desenvolvida

Para resolver a dor do cliente de forma acessível e rápida, optei por criar uma Aplicação Web (Web App) focada no agendamento e pré-encomenda de produtos. 

Escolhi a solução Web em vez de uma aplicação mobile porque ela elimina a barreira do download em lojas de aplicações. O cliente pode simplesmente aceder ao formulário através de um link no WhatsApp, Instagram ou apontando a câmara para um QR Code no próprio balcão.

A aplicação permite que o morador ou empresa local escolha o produto pretendido, informe a data e horário exato de retirada e adicione observações específicas para a produção, automatizando o fluxo que antes era feito à mão.

## Estrutura e Tecnologias

Desenvolvi a interface utilizando HTML5 semântico para estruturar os dados e CSS3 responsivo para garantir uma navegação agradável tanto no telemóvel quanto no computador, utilizando tons quentes que remetem à tradição do empório. A lógica de confirmação e resumo da encomenda em tempo real foi implementada com JavaScript puro.

O repositório foi organizado seguindo as boas práticas da disciplina, contando com a inclusão dos ficheiros de licença, configuração de ficheiros ignorados (.gitignore) para manter o projeto limpo e total proteção de credenciais.

## Como Testar o Projeto

Para testar a aplicação, basta clonar este repositório para o seu computador e abrir o ficheiro `index.html` em qualquer navegador web, ou aceder diretamente aos ficheiros pelo GitHub para visualizar o código.
